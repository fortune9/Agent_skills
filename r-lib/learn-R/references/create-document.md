### Document Structure Template

1. **Introduction**
   - What is the package/concept?
   - Why is it useful?
   - Core philosophy

2. **Installation & Setup**
   ```r
   install.packages("packagename")

3. Core Concepts (before detailed examples)
  - Key terminology
  - Mental models

4. Progressive Examples
  - Start simple
  - Build complexity gradually
  - Include realistic use cases

5. Common Patterns
  - Frequently used workflows
  - Recipe/template code

6. Comparisons (when relevant)
  - Compare with alternative approaches
  - When to use what
  - Pros/cons tables

7. Advanced Topics
  - Edge cases
  - Performance considerations
  - Integration with other tools
  
8. Resources
  - Official docs
  - Vignettes
  - Community resources
